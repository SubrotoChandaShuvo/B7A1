# TypeScript Solutions & Concepts

This repository contains my assignment for TypeScript & OOP

## Description

This project includes TypeScript and Object-Oriented Programming (OOP) practice problems and solutions. It focuses on understanding core programming concepts such as:

- Seven TypeScript Problems
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- TypeScript Utility Types (Pick, Omit)

## Technologies Used

- TypeScript
- Node.js
- JavaScript (basic usage)

## Project Structure

The repository is organized into different files based on topics and tasks. Each file contains a specific problem solution or concept implementation.
